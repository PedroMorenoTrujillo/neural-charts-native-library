# Changelog

## 0.1.0-beta.13

- Expand regression tests for chart data, tooltips, viewport gestures, linked panels, drilldown and accessible chart controls.

## 0.1.0-beta.10 - 2026-11-24

- Add a range navigator for numeric and time line charts, with a compact overview, draggable handles and accessible controls.
- Synchronize the navigator with chart zoom and reset the horizontal range independently of the vertical range.

## 0.1.0-beta.9

- Correct mobile chart touch handling and accessible labels.

## 0.1.0-beta.8 - 2026-11-23

- Align the supported Angular Native baseline with 0.27.0.

## 0.1.0-beta.7 — 2026-11-21

- Align framework dependencies and exact Angular Native peers with 0.25.0, including the Angular 22.3 web mount fix and Android color-scheme improvements.
- Preserve the Core 0.1.3 and SVG 15.15.4 baseline, and verify installation alongside Neural Native 0.1.0-beta.9.
- Do not report missing Variwide widths when the user has hidden every series. Keep the diagnostic for source data that really has no positive widths.

## 0.1.0-beta.6 — 2026-11-17

- Align Angular Native peers with 0.23.0 and retain the separate Charts and Neural Native public APIs.
- Read the framework haptics availability signal when checking device feedback support.
